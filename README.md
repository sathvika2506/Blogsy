# Blogsy

> An AI-powered full-stack blogging platform that combines content creation, intelligent search, and personalized article recommendations.

Blogsy is a full-stack blogging platform built with Node.js, Express.js, PostgreSQL, and EJS. It enables users to create, edit, and manage blog posts while enhancing the reading experience through AI-powered content search, semantic recommendations, and contextual question answering.

---

## Features

### User Authentication

* Secure Registration & Login
* Session-based Authentication
* Password Hashing
* Protected Routes

### Content Management

* Create Blog Posts
* Edit Existing Posts
* Delete Posts
* Rich Text Support
* Author Profiles

### AI Features

* Ask This Blog (OpenAI-powered contextual Q&A)
* Intelligent Blog Search
* NLP-based Content Recommendation Engine
* Semantic Similarity using TF-IDF and Cosine Similarity

### User Experience

* Bookmark Articles
* Dashboard
* Search Functionality
* Password Reset
* Responsive UI
